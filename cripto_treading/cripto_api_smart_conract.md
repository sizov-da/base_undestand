# Смарт-контракт — что это такое

Смарт-контракт — это программа, которая автоматически выполняется в блокчейне при соблюдении заранее определённых условий. Простыми словами, это самовыполняющийся цифровой договор.

## Основные свойства смарт-контрактов:

- **Автоматическое исполнение** — срабатывает без участия человека при выполнении условий
- **Неизменяемость** — после размещения в блокчейне код нельзя изменить
- **Прозрачность** — все операции видны всем участникам сети
- **Безопасность** — работает на основе криптографических принципов блокчейна

## Как это связано с USDT

USDT (Tether) существует как смарт-контракт в различных сетях:
- В Tron: TRC20-контракт с адресом `TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t`
- В Ethereum: ERC20-контракт с адресом `0xdAC17F958D2ee523a2206206994597C13D831ec7`

Этот смарт-контракт содержит:
- Функции для перевода токенов
- Механизм учета баланса каждого адреса
- Логику для проверки транзакций

## В вашем проекте

Когда вы создаёте кошелёк для пользователя, вы генерируете адрес, который может взаимодействовать с этим смарт-контрактом. Для операций с USDT ваше приложение будет отправлять транзакции к этому контракту через ноды, которые у вас уже настроены в docker-compose.

Для отправки USDT, например, вы обращаетесь к функции `transfer` смарт-контракта USDT с нужными параметрами (адрес получателя и сумма).
