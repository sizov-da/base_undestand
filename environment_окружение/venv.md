Настроить виртуальное окружение для Python — это простой процесс, который позволяет изолировать зависимости вашего проекта от глобальной системы. Вот пошаговая инструкция:

---

### Шаг 1. **Убедитесь, что Python установлен**
Проверьте, установлен ли Python на вашем компьютере, и узнайте его версию:

```bash
python3 --version
```
или
```bash
python --version
```

Если Python не установлен, скачайте его с [официального сайта Python](https://www.python.org/downloads/) и установите.

---

### Шаг 2. **Установите `venv`**
Для создания виртуальных окружений используйте модуль `venv`, который входит в стандартную библиотеку Python (начиная с Python 3.3).

Чтобы убедиться, что модуль установлен, выполните:
```bash
python3 -m ensurepip --upgrade
```

---

### Шаг 3. **Создайте виртуальное окружение**
Перейдите в папку вашего проекта и создайте виртуальное окружение:

```bash
python3 -m venv venv
```

Здесь:
- `python3` — команда для запуска Python 3.
- `venv` — название папки для виртуального окружения (вы можете выбрать любое имя, но обычно используют `venv`).

После выполнения команды создастся папка `venv`, содержащая изолированную установку Python.

---

### Шаг 4. **Активируйте виртуальное окружение**
Активируйте виртуальное окружение, чтобы начать использовать его:

#### На Windows:
```bash
venv\Scripts\activate
```

#### На Mac/Linux:
```bash
source venv/bin/activate
```

После активации в терминале появится название окружения, например:
```bash
(venv) user@computer:~/project$
```

---

### Шаг 5. **Установите зависимости**
После активации окружения вы можете устанавливать зависимости с помощью `pip`. Все установленные библиотеки будут изолированы внутри вашего окружения.

Пример:
```bash
pip install requests flask
```

Список установленных пакетов можно посмотреть командой:
```bash
pip list
```

---

### Шаг 6. **Сохраните зависимости**
Для сохранения всех установленных зависимостей в файл `requirements.txt` выполните:
```bash
pip freeze > requirements.txt
```

Этот файл можно использовать для установки зависимостей в будущем:
```bash
pip install -r requirements.txt
```

---

### Шаг 7. **Деактивируйте виртуальное окружение**
Когда вы закончите работу, деактивируйте окружение:
```bash
deactivate
```

---

### Шаг 8. **Удаление виртуального окружения**
Если вам больше не нужно виртуальное окружение, просто удалите папку `venv`:
```bash
rm -rf venv
```

---

### Советы:
- Для управления версиями Python можно использовать [pyenv](https://github.com/pyenv/pyenv).
- Если вы работаете с несколькими проектами, всегда используйте виртуальные окружения, чтобы избежать конфликтов между зависимостями.

Если у вас возникнут сложности или вопросы, дайте знать!
