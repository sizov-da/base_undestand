
# Vim

показать строки кода в редакторе Vim
```vi
    :set number
```
убрать строки кода в редакторе Vim
```vi
    :set nonumber
```


В `vi` или `vim` после поиска (`/текст` или `?текст`) используйте:

- `n` — перейти к следующему совпадению
- `N` — перейти к предыдущему совпадению

Поиск вперёд: `/текст`[cripto_treading](../cripto_treading)  
Поиск назад: `?текст`

#### Строки
- `w` — переход в начало следующего слова.
- `e` — переход в конец текущего или следующего слова. 
- `b` — переход в начало предыдущего слова.


# Табуляция в Vim

## Основные команды для табуляции

В нормальном режиме:
- `>>` — сделать отступ текущей строки
- `<<` — убрать отступ текущей строки
- `5>>` — сделать отступ для 5 строк вниз
- `5<<` — убрать отступ для 5 строк вниз

## Отступы для блоков кода
1. Выделите текст в визуальном режиме (нажмите `v`)
2. Нажмите `>` для добавления отступа или `<` для удаления

## Автоотступы в режиме вставки
- `CTRL-T` — добавить отступ в текущей строке
- `CTRL-D` — удалить отступ в текущей строке

## Настройка табуляции в конфигурации
```vim
:set tabstop=4      " Ширина табуляции в пробелах
:set shiftwidth=4   " Ширина отступов при использовании >> и <<
:set expandtab      " Использовать пробелы вместо символов табуляции
:set autoindent     " Автоматический отступ новых строк
```

Эти настройки можно добавить в файл `.vimrc` для постоянного использования.
