# Разработка структуры API и серверных сервисов.



### Разработка структуры API и серверных сервисов

Мы начнем с создания структуры API, определяя ключевые компоненты и сервисы, необходимые для работы серверной части проекта.

---

#### **1. Архитектура API**
API будет построено на **Laravel PHP** и взаимодействовать с **MongoDB** в качестве базы данных. API будет разделено на несколько сервисов:

1. **AuthService** – аутентификация и авторизация пользователей (JWT/OAuth2).
2. **UserService** – управление пользователями и ролями.
3. **ProjectService** – создание, обновление, удаление и просмотр проектов.
4. **StageService** – управление этапами проекта.
5. **FileService** – загрузка и управление файлами.
6. **NotificationService** – отправка уведомлений (email, WebSocket, Telegram).
7. **LoggingService** – логирование действий пользователей и API-запросов.

---

#### **2. Структура API**
Мы определим REST API эндпоинты для каждого сервиса:

##### **2.1 AuthService (Аутентификация и авторизация)**
| Метод | URL | Описание | Защита |
|-------|-----|----------|--------|
| POST | /api/auth/login | Вход пользователя | Нет |
| POST | /api/auth/register | Регистрация нового пользователя | Нет |
| POST | /api/auth/logout | Выход из системы | JWT |
| GET  | /api/auth/user | Получение информации о текущем пользователе | JWT |

##### **2.2 UserService (Пользователи)**
| Метод | URL | Описание | Защита |
|-------|-----|----------|--------|
| GET  | /api/users | Получить список пользователей | Admin |
| GET  | /api/users/{id} | Получить пользователя по ID | JWT |
| POST | /api/users | Создать пользователя | Admin |
| PUT  | /api/users/{id} | Обновить пользователя | Admin |
| DELETE | /api/users/{id} | Удалить пользователя | Admin |

##### **2.3 ProjectService (Проекты)**
| Метод | URL | Описание | Защита |
|-------|-----|----------|--------|
| GET  | /api/projects | Получить список проектов | JWT |
| GET  | /api/projects/{id} | Получить проект по ID | JWT |
| POST | /api/projects | Создать новый проект | JWT |
| PUT  | /api/projects/{id} | Обновить проект | JWT |
| DELETE | /api/projects/{id} | Удалить проект | Admin |

##### **2.4 StageService (Этапы)**
| Метод | URL | Описание | Защита |
|-------|-----|----------|--------|
| GET  | /api/stages | Получить список этапов | JWT |
| GET  | /api/stages/{id} | Получить этап по ID | JWT |
| POST | /api/stages | Создать новый этап | JWT |
| PUT  | /api/stages/{id} | Обновить этап | JWT |
| DELETE | /api/stages/{id} | Удалить этап | Admin |

##### **2.5 FileService (Файлы)**
| Метод | URL | Описание | Защита |
|-------|-----|----------|--------|
| POST | /api/files/upload | Загрузить файл | JWT |
| GET  | /api/files/{id} | Получить файл по ID | JWT |
| DELETE | /api/files/{id} | Удалить файл | Admin |

##### **2.6 NotificationService (Уведомления)**
| Метод | URL | Описание | Защита |
|-------|-----|----------|--------|
| GET  | /api/notifications | Получить список уведомлений | JWT |
| POST | /api/notifications | Создать уведомление | Admin |

##### **2.7 LoggingService (Логирование)**
| Метод | URL | Описание | Защита |
|-------|-----|----------|--------|
| GET  | /api/logs | Получить логи | Admin |

---

#### **3. Взаимодействие API с базой данных**
- Все сущности хранятся в **MongoDB**, используя коллекции:
   - `users` (пользователи)
   - `projects` (проекты)
   - `stages` (этапы)
   - `files` (файлы)
   - `notifications` (уведомления)
   - `logs` (логи)
- Используем **Eloquent ORM с Laravel MongoDB Driver**.

---

#### **4. Реализация кэширования и балансировки**
- **Redis** будет использоваться для хранения кэша.
- **NGINX + Laravel Octane** для балансировки нагрузки.

---

#### **5. Обеспечение безопасности API**
- **JWT-токены** для аутентификации пользователей.
- **Rate Limiting** для ограничения частоты запросов.
- **CORS-политика** для ограничения доступа из сторонних доменов.
